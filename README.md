# 🌌 La Galaxia de Orlando 🚗✨

Un regalo interactivo especial con una galaxia animada llena de carritos Hot Wheels, planetas girando y estrellas brillantes que forman el nombre **ORLANDO**.

## ✨ Características

- 🚗 **8 Carritos Hot Wheels** girando en órbita con diferentes colores
- 🪐 **4 Planetas** orbitando alrededor del centro con efectos luminosos
- ⭐ **300+ Estrellas** parpadeantes que crean un cielo mágico
- 💫 **Nombre "ORLANDO"** formado por estrellas brillantes en el círculo central
- 🌀 **Animación continua** - todo gira y se mueve de forma suave
- 📱 **Responsive** - funciona en cualquier dispositivo (móvil, tablet, PC)
- 🎨 **Efectos de luz** - Glow effects y sombras para mayor realismo

## 🚀 Cómo usar

1. **Abre el link en tu navegador:**

## 🛠️ Tecnología

- **HTML5** - Estructura de la página
- **CSS3** - Estilos y animaciones
- **JavaScript** - Canvas API para la animación en tiempo real

## 🎮 Cómo funciona

El proyecto utiliza `Canvas` de HTML5 para dibujar y animar:

- **Carritos**: Se dibujan como rectángulos estilizados que orbitan alrededor del centro
- **Planetas**: Círculos de diferentes colores con efectos de glow
- **Estrellas**: Puntos pequeños que parpadean aleatoriamente
- **Órbitas**: Líneas sutiles que muestran las trayectorias

Todas las animaciones son continuas y suaves, actualizándose 60 veces por segundo.
